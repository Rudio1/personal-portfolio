# Idioma

## Objetivo

Mostrar a interface em português ou inglês, lembrar a escolha neste browser e evitar texto cru de chave enquanto os JSON carregam.

## Onde está

- `src/contexts/TranslationContext.tsx`
- `messages/pt.json`
- `messages/en.json`
- Consumidores: `layout.tsx` (provider), `Header.tsx`, `page.tsx`, `projetos/page.tsx`, `ContactModal.tsx`
- Skeletons durante o loading: `src/components/LoadingSkeleton.tsx`

`next-intl` não participa desse fluxo.

## Regra de negócio

- Locale padrão escrito no código e no contexto inicial: `pt`.
- Persistência: `localStorage` chave `locale`.
- Idiomas com arquivo: `pt` e `en`. O Header só oferece esses dois.
- `changeLocale` aceita `string` e não valida o valor. Locale desconhecido esvazia os textos.
- Não há rota por idioma. A URL não muda.
- `<html lang>` permanece `pt` em `layout.tsx`, também quando o locale é `en`.
- `t` retorna `''` durante o loading, quando o cache do locale não existe, quando a chave falta ou quando o valor final não é string.
- Componentes de página usam `isLoading` para skeletons. `ContactModal` não usa `isLoading`; se aberto cedo, os rótulos podem aparecer vazios até o provider terminar. Na prática o modal começa fechado.

## Fluxo

Descrito em [DATA-FLOW.md](../architecture/DATA-FLOW.md). Os dois JSON são carregados juntos, uma vez por vida do módulo, para dentro de `translationsCache`.

## Entradas

Clique em Português ou English no dropdown desktop ou na seção mobile do Header.

## Saídas

Re-render com o outro catálogo. Nada é enviado ao servidor.

## Formato das chaves

Árvore JSON. Acesso por pontos: `projects.items.vegeta.title`.

Grupos de topo presentes nos dois arquivos: `navigation`, `language`, `home`, `projects`, `contact`. Os dois arquivos espelham a mesma estrutura. Manter esse espelho ao adicionar chave.

## Casos de erro

`import()` falho: `console.error('Error loading translations:', error)` e `isLoading` false. Não há fallback de cópia embutida além do cache vazio, então `t` continua devolvendo `''`.

## Observações

- O grupo `language` (`switch`, `current`) não é lido pelos componentes. O Header escreve `PT` / `EN` e os nomes dos idiomas no JSX.
- Bandeiras: `public/brazil.svg` e `public/usa.svg`, componente `FlagIcon` dentro de `Header.tsx`.
- Aria do seletor desktop: `"Select language"` fixo em inglês. Aria do botão do menu mobile: `"Fechar menu"` / `"Abrir menu"` fixos em português.
