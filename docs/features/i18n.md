# Idioma

## Objetivo

Mostrar a interface em português ou inglês, lembrar a escolha neste browser e evitar texto cru de chave enquanto os JSON carregam.

## Onde está

- `src/contexts/TranslationContext.tsx`
- `messages/pt.json`
- `messages/en.json`
- Consumidores: `layout.tsx` (provider), `Header.tsx`, `page.tsx`, `projetos/page.tsx`, `ContactModal.tsx`
- Skeletons durante o loading: `src/components/LoadingSkeleton.tsx`

`next-intl` não participa desse fluxo.

## Regra de negócio

- Locale padrão no primeiro render: `pt`.
- Persistência: `localStorage` chave `locale`.
- Idiomas com arquivo: `pt` e `en`. O Header só oferece esses dois. `changeLocale` ignora outro valor.
- Não há rota por idioma. A URL não muda.
- O servidor envia `<html lang="pt">`. No cliente, o provider define `document.documentElement.lang` com o locale ativo.
- Os JSON são import estático. `isLoading` é sempre `false`. `t` devolve `''` quando a chave falta ou o valor final não é string.
- Quem salvou `en` pode ver português por um instante, até o efeito ler o `localStorage`.

## Fluxo

Descrito em [DATA-FLOW.md](../architecture/DATA-FLOW.md). Os dois JSON entram no bundle do provider por import estático.

## Entradas

Clique em Português ou English no dropdown desktop ou na seção mobile do Header.

## Saídas

Re-render com o outro catálogo. Nada é enviado ao servidor.

## Formato das chaves

Árvore JSON. Acesso por pontos: `projects.items.vegeta.title`.

Grupos de topo presentes nos dois arquivos: `navigation`, `language`, `a11y`, `home`, `projects`, `contact`. Os dois arquivos espelham a mesma estrutura. Manter esse espelho ao adicionar chave.

## Casos de erro

Chave ausente: `t` devolve `''`. Não há `import()` dinâmico nem skeleton de tradução.

## Observações

- O grupo `language` (`switch`, `current`) não é lido pelos componentes. O Header escreve `PT` / `EN` e os nomes dos idiomas no JSX.
- Bandeiras: `public/brazil.svg` e `public/usa.svg`, componente `FlagIcon` dentro de `Header.tsx`.
- Aria do seletor de idioma, do menu e do skip link vêm de `a11y` nos JSON.
